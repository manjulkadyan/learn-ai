# Curriculum topics

The curriculum uses this progression:

```text
Topic → Subtopic → Learning units → Practice project → Mastery checkpoint
```

| Topic | Subtopics | Topic project |
|---|---|---|
| [Foundations](foundations.md) | AI mental models; Python for AI; numerical computing; data analysis; mathematics | Reproducible data-to-prediction analysis |
| [Machine learning](machine-learning.md) | Problem framing; data preparation; regression; classification; trees; clustering; evaluation and generalization | Dataset-to-model decision report |
| [Deep learning](deep-learning.md) | Tensors; networks; losses; backpropagation; optimizers; CNNs; sequence models; transformers | Trained and evaluated model with shape walkthrough |
| [Generative AI and LLMs](generative-ai.md) | Language-model foundations; transformer internals; lifecycle; application patterns; safety and evaluation | Grounded assistant with versioned evaluation |
| [AI engineering](ai-engineering.md) | System boundaries; serving; evaluation; observability; security; reliability; cost and scale | Operable service with rollback and runbook |
| [On-device AI/ML](on-device-ai.md) | Inference contract; formats and runtimes; compression; performance; product behavior | Benchmarked Android feature |
| [Specializations](specializations.md) | Vision; speech; multimodal; diffusion; recommendation; reinforcement learning; graph ML; efficient inference; privacy | One chosen specialization project |
| [Research, open source, and career](research-career.md) | Research practice; open source; portfolio and system design | Reproducible contribution and evidence-based case studies |

Start with [Foundations](foundations.md). The order across topics is a suggested dependency route. Choose optional branches deliberately and use each subtopic's checkpoint to track progress. Pacing is personal; completion is based on demonstrated mastery and evidence, not calendar speed.
