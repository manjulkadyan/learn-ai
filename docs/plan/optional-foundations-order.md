# Optional foundations route

This page offers one possible order through the [Foundations topic](../topics/foundations.md). It is a planning aid, not a monthly plan or required sequence. The foundations subtopics and their checkpoints define the curriculum; use this route only if it helps you decide what to study next.

## Suggested route

1. **AI mental models.** Study rules versus learning, examples and labels, training and inference, evaluation, and model limitations. Use the existing [AI mental models lesson](../lessons/ai-mental-models.md) and [learning loop lesson](../lessons/learning-loop.md). Artifact: a data-to-prediction trace.
2. **Python for AI.** Practice values, control flow, functions, files, exceptions, debugging, and reproducibility. Use [Python and reproducible AI work](../lessons/python-reproducibility.md). Artifact: a small script that reads and explains example predictions.
3. **Numerical computing.** Learn NumPy arrays, shapes, indexing, broadcasting, vectors, and matrices. Artifact: a shape-first notebook.
4. **Data analysis.** Practice pandas, cleaning, grouping, joins, and visualization. Artifact: a cleaned dataset, data-quality note, and charts.
5. **Mathematics.** Build linear algebra, gradients, probability, statistics, and optimization as needed. Artifact: a hand-worked prediction and parameter update.
6. **Machine learning.** Continue to the [Machine learning topic](../topics/machine-learning.md) when the foundations checkpoints relevant to your project are demonstrated. Artifact: a leakage-safe model report with error analysis.

Adjust the order when prior experience or the project makes a prerequisite clear. Split a subtopic across any number of sittings. Record progress from artifacts and checkpoint evidence, not a deadline.
