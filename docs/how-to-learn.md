# How to learn from this curriculum

The curriculum is organized as:

```text
Topic
  → Subtopic
    → Learning units
      → Practice project
        → Mastery checkpoint
```

Topics group related skills. Subtopics define a useful area of competence. Learning units break that area into concepts and actions. A practice project combines those units into an artifact. The mastery checkpoint describes what you should be able to explain or demonstrate with that artifact.

## Choose a pace that fits

Days, weeks, session counts, and time estimates are optional planning aids. One learner may work through array shapes in two sittings; another may need several more. Neither pace determines progress. Use prerequisites to find a sensible starting point, then move on when you have evidence for the checkpoint. Revisit a unit or checkpoint when later work exposes a gap.

You do not need to complete every specialization. Foundations and the core ML, deep-learning, generative-AI, and engineering paths build shared capability; specializations are chosen based on the problems you want to solve.

## A learning unit loop

Use these steps as needed; they are a menu for learning, not a timed agenda:

1. Read the beginner explanation and note unfamiliar vocabulary.
2. Study the diagram or illustration, then work through the example by hand.
3. Run or write the code practice. Change an input and predict what will happen first.
4. Try an exercise without looking at the solution guidance, then explain any correction.
5. Record a common mistake you can now recognize or prevent.

## Track mastery with evidence

Do not mark a subtopic complete because you opened its page or finished a number of sessions. Compare your work with the mastery checkpoint. Record the artifact, what you can explain, what you can implement, and any remaining gap in [Progress](progress.md). Mark it demonstrated when the evidence meets the checkpoint; otherwise note what to practice next.

```text
Subtopic:
Checkpoint status: blank / practicing / demonstrated
Evidence or artifact:
I can explain:
I can implement:
One remaining gap:
Next practice:
```

## Learning content standard

Each subtopic provides a beginner explanation, prerequisites, concepts and vocabulary, a worked example, an illustration or animation, code practice, common mistakes, exercises with solutions, a practice project, and a mastery checkpoint. Use the topic pages as the curriculum source of truth; supporting standalone lessons and books deepen selected learning units.

Keep a running notebook for new terms, assumptions and shapes, failure modes, and connections to systems you already know.
