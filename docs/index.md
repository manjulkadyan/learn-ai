# AI Engineering Learning Lab

Welcome. This is a deliberate path from **“I can build software, but I do not yet understand AI”** to **“I can design, train, evaluate, deploy, and operate AI systems—including on phones.”**

You do not need a mathematics degree or prior ML experience. You do need patience and a willingness to make small things work before jumping to impressive things.

!!! tip "Start here"
    Begin with the [Foundations topic](topics/foundations.md) and its AI mental models subtopic. The existing [AI mental models lesson](lessons/ai-mental-models.md) is a supporting lesson, not a day on a schedule. First learn the difference between normal software, a model, training, and inference.

## The destination

The course eventually connects four layers:

| Layer | Question | Example outcome |
|---|---|---|
| Foundations | How do numbers, data, probability, and optimization work? | Explain why a model can improve from examples. |
| Machine learning | How does a model learn a useful pattern? | Train and evaluate a classifier without fooling yourself. |
| AI engineering | How do we ship a reliable AI feature? | Build an API, evaluation set, monitoring, and fallback. |
| On-device AI | How do we run intelligence privately and quickly on hardware? | Convert, quantize, benchmark, and ship a mobile model. |

## How the material is organized

Each subtopic is built from learning units and includes a practice project and mastery checkpoint. Topic pages provide illustrations or diagrams and link to supporting lessons where useful. Completion is based on the artifact and demonstrated understanding, not lesson count.

The local [resource library](resource-library.md) maps the added PDF collection to the curriculum. Use it as a staged reference shelf, not as a requirement to read everything.

The visible structure is **Topic → Subtopic → Learning units → Practice project → Mastery checkpoint**. Mermaid diagrams illustrate each subtopic flow; pacing is optional and progress follows demonstrated mastery.
