# Glossary

**AI (artificial intelligence).** A broad name for systems that perform tasks we associate with intelligent behavior, such as recognizing speech or choosing an action.

**Dataset.** A collection of examples used to inspect, train, validate, or test a system.

**Feature.** An input value used by a model, such as word count, pixel intensity, or screen width.

**Inference.** Using a trained model to produce an output for new input.

**Label/target.** The answer an example is meant to predict.

**Machine learning.** A family of methods in which a system learns a useful mapping from examples rather than relying only on hand-written rules.

**Model.** A parameterized function that maps input to output.

**Parameter.** A value inside a model that learning can adjust.

**Training.** The process of using examples and an objective to adjust model parameters.

**Evaluation.** Measuring how well a model works on data and conditions that represent its intended use.

**On-device inference.** Running model inference on the user’s phone, tablet, wearable, or other local hardware rather than sending the input to a server.
