# AI Engineering Learning Lab

This is a personal, from-zero-to-professional curriculum for AI engineering, machine learning, modern generative AI, and on-device AI/ML. It is organized by topic mastery rather than days: **Topic → Subtopic → Learning units → Practice project → Mastery checkpoint**.

It is written for an experienced Android/Kotlin engineer who is new to the underlying ideas. Each subtopic is designed to answer five questions:

1. What problem does this idea solve?
2. What is the simplest useful mental model?
3. What is happening technically and mathematically?
4. How do I use it in code and in a real product?
5. How do I know that I truly understand it?

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Open <http://127.0.0.1:8000>.

## Learning rule

Pacing is optional. Read the explanation, work the example, practice with code, and use the checkpoint to decide what to revisit. Record evidence of mastery in [Progress](docs/progress.md); elapsed time and pages read do not determine completion. Start at [Foundations](docs/topics/foundations.md).
